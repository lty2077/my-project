读书实践周总结

在本次读书实践周中，我主要围绕“毕业设计推进”和“专业知识补充”两个方面展开安排。结合当前毕设阶段，我将时间重点放在模型训练优化与论文内容完善上，同时补充阅读了与语音欺诈检测相关的部分论文资料。

在毕设推进方面，本周主要完成了卷积神经网络模型的进一步训练与测试工作。在实际实验过程中，我对比了基础CNN模型与加入数据增强后的模型效果。通过多次训练可以发现，在加入高斯噪声和时间拉伸后，模型在测试集上的表现相对更加稳定，尤其是在存在一定噪声干扰的情况下，分类结果波动有所减小。不过，在实验中也遇到了一些问题，例如模型在不同批次测试中EER值存在波动，以及在早期调试阶段曾出现输入维度不匹配的问题。针对这些情况，我重新检查了特征处理流程，并统一了MFCC特征尺寸，最终使模型能够正常运行并完成评估。

在专业学习方面，我结合毕设内容，重点阅读了语音欺诈检测和语音特征提取相关的论文资料，对MFCC特征提取流程以及CNN在语音任务中的应用有了更具体的理解。相比之前仅停留在原理层面的认识，通过结合自己实验过程进行对照理解，能够更清楚地认识到不同处理步骤对最终模型效果的影响。例如，在阅读相关文献后，我对数据增强在提升模型泛化能力方面的作用有了更直观的认识，这也为后续优化模型提供了一些思路。

总体来看，本周实践安排与毕设进度基本保持一致。一方面通过实验推进了模型训练工作，另一方面通过阅读相关资料补充了理论理解。虽然目前模型性能仍有提升空间，但整体流程已经逐步稳定。后续将继续在模型结构优化和论文撰写方面进一步完善，使毕业设计能够顺利完成。
